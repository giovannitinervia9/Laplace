# Laplace reference manual

This is the reference documentation of Laplace's C++ library: one entry per
public function, grouped by module. The modules are listed under **Topics**
in the side bar.

See \ref accuracy "How accuracy is measured" for how accuracy figures, error metrics, and test bounds in this manual are defined and obtained. See \ref derivation "How formulas are derived" for how the analytic formulas inside Laplace are obtained.

Laplace is in early development and has no stable API yet. The source is at
[github.com/giovannitinervia9/Laplace](https://github.com/giovannitinervia9/Laplace).
