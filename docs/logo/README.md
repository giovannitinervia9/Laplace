# Laplace logo

The symbol is two ribbons. The front ribbon (blue) is an asymmetric density, a
gamma distribution with shape 3. The ribbon behind it (orange) is its Laplace
approximation: the Gaussian with the same mode and the same curvature of the log
density at the mode. The two meet at the peak and separate along the sides. The
wordmark is Montserrat Alternates Bold (SIL Open Font License 1.1), converted to
outlines.

| File | Use |
|---|---|
| `laplace-logo-light.svg`, `.png` | horizontal logo for light backgrounds |
| `laplace-logo-dark.svg`, `.png` | horizontal logo for dark backgrounds |
| `laplace-logo-black.svg`, `laplace-logo-white.svg` (and `.png`) | single colour |
| `laplace-logo-stacked-*.svg`, `.png` | symbol above the wordmark, same four variants |
| `laplace-icon-{light,dark}.svg`, `laplace-icon-{light,dark}-{16,...,512}.png` | symbol only |
| `laplace-icon-{black,white}.svg`, `-512.png` | symbol only, single colour |
| `favicon.ico` | 16, 32, 48 and 64 px |

PNG files have a transparent background. Colours: blue `#3a6fd6` (upper face)
and `#1d3f8f` (lower face), orange `#e69a2e` and `#a8650c`, text `#1d2433`; on
dark backgrounds blue `#5585e6` and `#2a4f9e`, orange `#f0a640` and `#b9701a`,
text `#f2f4f8`.
